# Esquadrilha de Papel ✈️

Jogo web em HTML5 Canvas inspirado na sensação de um jogo de tiro desenhado em caderno, mas com identidade própria baseada em aviões de papel.

## Como jogar

- **Celular:** arraste o dedo para pilotar; os tiros são automáticos; segure o botão **IMPULSO** para acelerar.
- **Computador:** use **WASD** ou as setas; segure **Espaço** para usar o impulso.
- Sobreviva às ondas, escolha melhorias ao subir de nível e enfrente um chefão a cada 5 ondas.

## Recursos da versão atual

- Visual de folha de caderno
- Aviões de papel desenhados em Canvas
- Controle por toque, mouse e teclado
- Tiro automático no inimigo mais próximo
- Ondas progressivas
- Chefões
- Sistema de combo e pontuação
- Melhorias roguelite durante a partida
- Escudo, recuperação de vida e impulso
- Layout responsivo para iPhone e desktop
